YOUR PRIVATE CONNECTION

Bring your workspace to life.

Connect the existing Supabase project. Local-only mobile trips remain on their devices.

  1. Configure the project

    Add the project HTTPS URL and public publishable key to admin/.env.local. The root app's public settings are also supported. Read-only access and profile editing use the public key plus your administrator session. Invitations additionally need a server-only secret.

  2. Apply the database setup

    In your project's Supabase SQL editor, run backend/supabase.sql, then backend/admin.sql, backend/auth-profiles.sql and backend/user-management.sql for a new setup. For the existing project, apply only the new migration. This adds admin access without replacing mobile policies.

  3. Grant an existing account access

    Confirm its email, copy its UUID from Authentication → Users, then run this only in the trusted SQL editor:

    insert into public.waylo_admins(user_id)
values ('YOUR-USER-UUID');
  4. Restart and sign in

    Restart npm.cmd run admin:start, then sign in here. Admin permissions are checked in the database on every request.
